## Netflix TV Shows & Movies Analysis
### 📊 Project Overview

The dataset contains 5,283 Netflix titles with 11 attributes, including movie/TV show type, title, description, release year, age certification, runtime, IMDb ID, IMDb score, and IMDb votes.

The project uses Excel to explore the characteristics and performance of Netflix content and identify patterns across different dimensions.

### 🔍 Key Analysis Areas
-  Content Type Analysis – Comparison of Movies vs. TV Shows
-  Release Year Analysis – Distribution and trends of content across years
-  Age Certification Analysis – Understanding content ratings and audience categories
-  Runtime Analysis – Analysis of movie/show duration
-  IMDb Score Analysis – Identification of highly-rated content
-  IMDb Votes Analysis – Understanding audience engagement through voting activity

## 🛠️ Tools & Techniques
- Microsoft Excel
- Microsoft PowerBI
