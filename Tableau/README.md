## 🏠 StayCatin – Rental Property Analytics
### 📊 Project Overview

The StayCatin dataset contains detailed information about rental properties, including property type, room type, location, pricing, minimum stay requirements, number of reviews, host information, accommodation capacity, and review scores.

The project uses Tableau to transform the raw rental data into interactive dashboards and visualizations, making it easier to identify pricing patterns, property trends, customer preferences, and location-based insights.

## 🔍 Key Analysis Areas
- Property Analysis – Analysis of different property and room types.
- Price Analysis – Comparison of rental prices across locations and property types.
- Location Analysis – Exploration of listings across different neighbourhoods and cities.
- Availability Analysis – Analysis of property availability and daily pricing.
- Review Analysis – Evaluation of customer ratings and review scores.
- Host Analysis – Understanding host activity and listing distribution.
- Property Characteristics – Analysis of bedrooms, bathrooms, beds, and accommodation capacity.
- Tableau Visualizations

### The project uses Tableau to create interactive visualizations for:

- Price and availability trends
- Listings by location
- Property and room-type distribution
- Review score analysis
- Host and listing analysis
- Accommodation capacity
- Geographic distribution of properties
